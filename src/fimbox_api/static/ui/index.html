Remembered workspaces

Workspaces you create or open are remembered for your account in this browser. Opening checks your current access. Forget only removes the browser shortcut, not shared data.

    Create at s3://resource/<resource_id>/data/contents/<empty_subprefix>: the workspace subprefix must be a new, empty child beneath the resource’s data/contents/ (no existing files or folders). Do not choose the resource root or data/contents/ itself. Creating requires HydroShare write access. Read-only users can open workspaces and view existing results. Opening verifies the workspace with the server; job results are stored inside it.

    Reach set

    Add each HUC and reach once, then use the same reach set to create a single scenario or timestep scenarios. Every generated scenario includes every reach in this set.

    The reach set contains only HUCs and ReachIDs. Enter flows in each scenario, or select one streamflow source and UTC time for all its reaches.

    Load a streamflow source for every reach in the set, then choose shared UTC times to create scenarios.

    Reach set map

    Blue features show the reach set; red shows the clicked reach. Click a stream, then choose Add to reach set. NHDPlus v2.1 COMIDs are NWM ReachIDs. Flowlines appear at zoom ≥ 11. HUC8 boundaries may take a few seconds to load. A reach must exist in the HAND hydrofabric for the job to map it; flow selection is separate from the map.

    Scenarios to submit

    Choose a streamflow source and period for the whole scenario or timestep batch. Only exact UTC times shared by every reach are available; missing samples are not interpolated. This workflow does not require the map.
